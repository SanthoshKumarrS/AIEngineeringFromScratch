# How to Run

Clone the repository:

```bash
git clone https://github.com/<your-username>/AIEngineeringFromScratch.git
cd AIEngineeringFromScratch
```

Create a virtual environment:

```bash
uv venv
source .venv/bin/activate
```

Install dependencies:

```bash
uv sync
```

Or, if a lock file is not present:

```bash
uv pip install -r requirements.txt
```
